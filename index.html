AI Tools

I've integrated AI tools into my development workflow to meaningfully improve productivity and delivery speed. That means knowing when to use them, when not to, and always verifying the output.

Claude Code

My go-to for complex reasoning, code review, and architecture discussions. Runs as a CLI in the terminal, making it feel like pair programming. I use it for iterative development, refactoring, and especially like the planning mode feature.

Codex

OpenAI's agentic coding tool, built for terminal-first development workflows. I use it for scaffolding, refactoring tasks, and letting it run autonomously on well-scoped problems. I like it because it can iterate without hand-holding, allowing me to focus on higher-level decisions.

GitHub Copilot

IDE-integrated autocompletion that reduces friction during day-to-day coding. Even when I need to write code from scratch, Copilot helps me stay in the flow by suggesting completions and entire functions based on context.
